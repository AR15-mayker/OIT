Служба каталогов — это система управления информацией, представляющая собой централизованное хранилище данных о ресурсах сети, пользователях, группах, приложениях и других объектах. Она обеспечивает структурированное хранение, управление доступом и возможность поиска этой информации. Службы каталогов играют важную роль в автоматизации и оптимизации бизнес-процессов, позволяя управлять пользователями, ресурсами и политиками безопасности в масштабе всей организации.

Объекты, описываемые в каталоге информационной системы
Каталоги информационных систем могут содержать различные типы объектов, такие как:

Пользователи: информация о сотрудниках компании, включая имена, должности, контактные данные и права доступа.
Группы: наборы пользователей, объединённые по определённым критериям (например, отделы).
Компьютеры: сведения о сетевых устройствах, их конфигурации и правах доступа.
Приложения: информация о программах и сервисах, используемых в организации.
Политики безопасности: правила и параметры, определяющие доступ к различным ресурсам.
Ресурсы: файлы, папки, принтеры и другие устройства, доступные через сеть.
Схема каталога
Схема каталога определяет структуру и тип данных, которые могут храниться в службе каталогов. Основные элементы схемы включают:

Атрибуты: характеристики объекта (имя, адрес электронной почты, пароль и т.д.).
Классы объектов: категории объектов, таких как пользователи, группы, компьютеры.
Правила наследования: механизмы передачи атрибутов от родительских классов объектам-потомкам.
Структура службы каталогов Windows (Active Directory)
Active Directory состоит из следующих основных единиц:

Домены: основная единица логической структуры, содержащая пользователей, группы и ресурсы.
Организационные подразделения (OU): контейнеры внутри домена для группировки объектов по различным признакам.
Контроллеры домена: серверы, обеспечивающие аутентификацию и авторизацию пользователей.
Деревья доменов: иерархические структуры, состоящие из связанных доменов.
Леса доменов: объединение деревьев доменов, позволяющее создавать глобальные каталоги.
Сайты: физические структуры, отражающие географическое расположение ресурсов и пользователей.
Организационное подразделение (OU)
Organizational Unit (OU) — это контейнер в Active Directory, используемый для логического группирования объектов (пользователей, компьютеров, групп). OU позволяют делегировать административные полномочия и применять политики безопасности к определённой группе объектов.

Функции домена в Active Directory
Домен в Active Directory выполняет следующие основные функции:

Обеспечивает централизованную аутентификацию и авторизацию пользователей.
Хранит информацию о пользователях, группах и ресурсах.
Применяет политики безопасности и управляет правами доступа.
Поддерживает интеграцию с DNS для разрешения имён.
Дерево доменов и пространство имён
Дерево доменов представляет собой иерархию доменов, связанных доверительными отношениями. Оно образует единое пространство имён, где каждый домен имеет уникальное имя в формате DNS (например, example.com → sub.example.com). Пространство имён позволяет уникально идентифицировать каждый объект в каталоге.

Лес доменов
Лес доменов объединяет несколько деревьев доменов, каждое из которых имеет своё собственное пространство имён. Леса обеспечивают глобальную доступность информации между деревьями и позволяют организациям с различными доменными именами взаимодействовать друг с другом.

Связи сайтов: маршруты для репликации данных между сайтами.
Сайт в Active Directory
Сайт в Active Directory представляет собой набор подсетей, объединённых общими характеристиками связи (например, скоростью передачи данных). Сайты используются для оптимизации трафика репликации и управления доступом к ресурсам на основе физического расположения.

Использование сайтов для настройки доступа и репликации
Сайты помогают оптимизировать трафик репликации, уменьшая нагрузку на сеть. Они также позволяют настраивать политику доступа, обеспечивая более эффективное использование сетевых ресурсов.

DN и RDN
Distinguished Name (DN) — уникальный полный путь к объекту в каталоге, включающий все уровни иерархии до корня дерева. Relative Distinguished Name (RDN) — относительное имя объекта, указывающее только на ближайший контейнер.

Идентификация объектов в каталоге
DN и RDN используются для уникальной идентификации каждого объекта в каталоге. DN описывает полный путь, а RDN — относительный путь внутри контейнера.
